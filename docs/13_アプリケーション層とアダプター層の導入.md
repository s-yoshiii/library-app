`dataAccess/` は命名が層を示していなかったが、`adapter/repositories/` に変えることで役割が明確になった。

## AddBookUseCase の実装

```typescript
export class AddBookUseCase implements AddBookUseCaseInterface {
  constructor(
    private readonly bookRepository: BookRepositoryInterface,
    private readonly idGenerator: IdGeneratorInterface,
  ) {}

  async execute(requestDto: AddBookRequestDto): Promise<AddBookResponseDto> {
    const id = this.idGenerator.generate();
    const newBook = new Book(id, requestDto.title);
    const createdBook = await this.bookRepository.create(newBook);
    return {
      id: createdBook.id,
      title: createdBook.title,
      isAvailable: createdBook.isAvailable,
      createdAt: createdBook.createdAt,
      upDatedAt: createdBook.upDatedAt,
    };
  }
}
```

### DTO（Data Transfer Object）の役割

| クラス | 方向 | 内容 |
|--------|------|------|
| `AddBookRequestDto` | Controller → UseCase | `title: string` のみ |
| `AddBookResponseDto` | UseCase → Controller | id, title, isAvailable, 日付 |

DTO を挟むことで、UseCase は Express の `Request`/`Response` を知らなくていい。
HTTP の変更が UseCase に伝わらない。

---

## IdGeneratorInterface の意義

```typescript
export interface IdGeneratorInterface {
  generate(): string;
}
```

`AddBookUseCase` は「ID を生成するなにか」に依存するが、それが UUID なのかナノID なのかは知らない。
Domain 層にインターフェースを置くことで、UseCase は実装に依存しない。

実装クラス（`UUIDGenerator` など）は Infrastructure／Adapter 層に置く予定。

## 修正したバグ

### 1. `app.ts` のインポートパスがずれていた

```typescript
// Before（削除済みのパスを参照していた）
import { PrismaBookRepository } from './dataAccess/PrismaBookRepository.js';

// After
import { PrismaBookRepository } from './adapter/repositories/PrismaBookRepository.js';
```

### 2. `PrismaBookRepository` のコンストラクタ引数が不要だった

```typescript
// Before（引数を受け取るが、コンストラクタ内で即座に上書き → 無意味）
constructor(private readonly prisma: PrismaClient) {
  const adapter = new PrismaLibSql({ ... });
  this.prisma = new PrismaClient({ adapter }); // ← 引数を無視して作り直している

// After（引数を削除してクリーンに）
private readonly prisma: PrismaClient;

constructor() {
  const adapter = new PrismaLibSql({ ... });
  this.prisma = new PrismaClient({ adapter });
}
```
